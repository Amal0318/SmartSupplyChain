# 🔌 REST APIs & API Documentation

## Base URL
`http://localhost:8000/api/v1`

---

## 1. Authentication Endpoints (`/auth`)
- `POST /auth/login`: Authenticate user and issue JWT bearer token.
- `POST /auth/register`: System admin registers new staff accounts.
- `GET /auth/me`: Fetch current authenticated user role and profile metadata.

## 2. Procurement Endpoints (`/procurement`)
- `GET /procurement/requisitions`: List purchase requisitions (filter by status, date).
- `POST /procurement/requisitions`: Create new Purchase Requisition (PR).
- `PUT /procurement/requisitions/{id}/approve`: Approve PR (Procurement Manager).
- `PUT /procurement/requisitions/{id}/reject`: Reject PR with remarks.
- `POST /procurement/rfq`: Create RFQ and send to suppliers.
- `GET /procurement/orders`: List Purchase Orders (POs).
- `POST /procurement/orders`: Generate PO from approved PR/RFQ.
- `PUT /procurement/orders/{id}/approve`: Sign and issue PO.

## 3. Inventory & Warehouse Endpoints (`/inventory`)
- `GET /inventory/products`: List product catalog with stock balances and reorder alerts.
- `POST /inventory/products`: Add new product SKU to catalog.
- `POST /inventory/grn`: Create Goods Receipt Note (GRN) upon physical delivery.
- `POST /inventory/qc`: Log Quality Inspection result (Accepted / Rejected / Partial Qty).
- `POST /inventory/transfers`: Process stock transfer between warehouse bin locations.
- `GET /inventory/transactions`: Query immutable stock audit logs.

## 4. Production & Logistics Endpoints (`/production`, `/logistics`)
- `POST /production/work-orders`: Generate new Work Order referencing BOM.
- `GET /logistics/shipments`: Track shipment status and carrier ETA feeds.

## 5. Multi-Agent Control Tower Endpoints (`/ai/control-tower`)
- `GET /ai/agents/health`: Return real-time heartbeat and health status of all 5 AI agents.
- `GET /ai/agents/insights`: Fetch insights generated by Procurement, Inventory, Production, and Logistics agents.
- `GET /ai/control-tower/report`: Fetch live Executive Control Tower Report (Risk Level, Confidence Score, Recommendations).
- `POST /ai/agents/{agent_name}/trigger`: Manually trigger a domain agent analysis cycle.
- `POST /ai/control-tower/simulate-failure`: Developer test endpoint to simulate agent failure and verify fault tolerance fallback.
