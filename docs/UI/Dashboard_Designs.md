# 🎨 UI/UX Wireframes, Dashboard Designs & User Flows

## 1. Design System & Aesthetics
- **Color Palette**: Dark enterprise mode with crisp HSL accents (Deep Navy `#0F172A`, Electric Blue `#3B82F6`, Emerald Green `#10B981`, Amber Warning `#F59E0B`, Crimson Reject `#EF4444`).
- **Typography**: Inter / Outfit sans-serif fonts for high data legibility.
- **Micro-Interactions**: Hover card subtle elevation, real-time KPI badge pulses, interactive flowchart status nodes.

## 2. Executive & Operational Dashboard Interfaces
1. **Executive Dashboard**: High-level KPIs (Total Procurement Spend, Inventory Turnover, On-Time In-Full Supplier Score, Active Work Orders).
2. **Procurement Manager Dashboard**: Pending PR approvals, RFQ responses comparison matrix, open PO status pipeline.
3. **Inventory Controller Dashboard**: Live stock levels, Reorder Alert list, Warehousing Bin Occupancy heat map, GRN receiving queue.
4. **Interactive Workflow Map Component**: Visual node graph representing Stage A $\rightarrow$ Stage G with live document status counters.
